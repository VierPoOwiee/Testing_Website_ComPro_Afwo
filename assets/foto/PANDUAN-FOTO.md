# Panduan Foto Layanan

Taruh foto di folder ini dengan **nama file persis** seperti tabel di bawah (huruf kecil, format `.jpg`). Tidak perlu mengubah kode.
Kalau file belum ada, kartu layanan menampilkan pelat monogram yang rapi, jadi website tetap tampak utuh.

**Spesifikasi:** potret rasio 4:5 (contoh 1000×1250 px), JPG, usahakan di bawah 300 KB (kompres dulu di squoosh.app). Wajah/rambut di tengah, karena kartu dipotong otomatis.

**Prioritas (★):** 8 foto yang tampil di beranda (hero dan slider layanan). Sisanya muncul saat layanan dibuka di halaman "Semua Layanan".

## Catatan penting

- Unsplash dan Pexels boleh dipakai gratis termasuk untuk komersial, tapi **cek halaman tiap foto** sebelum memakainya.
- Foto stok jangan diakui sebagai hasil kerja salon. Section "Galeri Karya" sebaiknya diisi foto hasil kerja Afwo sendiri; untuk foto klien asli, minta izin tertulis dulu.
- Simpan juga catatan sumber tiap foto (nama fotografer dan link) untuk jaga-jaga.


## Foto referensi Gaya Potong (khusus wanita)

Folder: **`assets/foto/gaya/`**. Ada 24 foto hasil kerja Afwo, formatnya `.jpeg` dengan rasio 4:5 atau 9:16 (dipotong otomatis ke 4:5).
Daftar gaya ada di `src/main.js` (cari `const GAYA`). Tiap baris berisi: nama kartu, jenis potongan, penjelasan, kata kunci Pinterest, dan nama file foto.

**Menambah gaya baru:** taruh fotonya di folder ini, lalu tambahkan satu baris di `GAYA` dengan nama file (tanpa `.jpeg`). Jenis potongan yang dikenali filter: Layer, Bob, Curtain Bangs, Butterfly, Pixie. Jenis baru otomatis butuh ditambahkan di `GAYA_GROUPS`.

**Foto yang sudah dipakai di Galeri Karya** tidak diulang di sini. Kartu gayanya tetap bisa dipilih, tetapi area fotonya berisi teks nama bayangan dan link ke Galeri Karya. Daftar foto galeri dibaca otomatis dari halaman, jadi kalau foto di galeri berubah, referensi ikut menyesuaikan. Kartu berfoto selalu tampil lebih dulu.

**Mengganti nama kartu:** ubah teks pertama di baris `GAYA`; nama file foto tidak perlu ikut diganti.

## Foto layanan yang belum punya file sendiri

Hero, slider layanan, dan daftar "Semua Layanan" memakai foto salon di folder `gaya/` sebagai cadangan sementara. Begitu kamu menaruh file `<nama-layanan>.jpg` di folder ini (lihat tabel di atas), foto itu otomatis menggantikannya.

Layanan yang tidak punya cadangan yang cocok (Potong Pria, Potong Anak, Perm Akar, Cold Perm, Hairmask, Treatment Komplit, Hair Detox) tetap menampilkan pelat monogram sampai fotonya ditambahkan. Pemetaan cadangan ada di `src/main.js` (cari `SVC_FB`).
